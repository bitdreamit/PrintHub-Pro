Chapter 1

What is PrintHub Pro

Three small parts that work together to print without any dialog box.

PrintHub Pro is a local printing bridge. When a PDF or a web page should go to paper, it sends the job straight to your printer — no print dialog, no extra clicks, no browser print preview. It runs entirely on your own computer, so no document ever leaves your network. You install it once, and after that printing happens quietly in the background every time.

The system has three parts. The Chrome extension watches your browser: it catches PDF links, right-click prints, and button clicks. The print hub is a small background program that receives print jobs from the extension and talks to Windows, Linux or macOS. The printer engine is the software that actually pushes paper: SumatraPDF on Windows (silent PDF printing), or the built-in CUPS system on Linux and macOS.

100% Local

The hub binds to 127.0.0.1:9235 only. Jobs, history and settings stay in a folder under your user profile. No cloud service, no account, no telemetry.

Token Protected

Every request must carry the token PrintHub-2024. Other programs or websites cannot send jobs to your printer without it.

Tray Icon & Auto-Run

After one-time installation the hub shows a “PrintHub Pro” tray icon near the clock (right-click: status page, test page, pause, auto-run, exit) and starts by itself at every logon — a visible Startup app on Windows (Task Manager → Startup apps), a systemd user service on Linux, a LaunchAgent on macOS. The hub runs as PrintHubPro.exe, never as “python”.

History & Reprint

The last 100 jobs are stored with status and timing. Any job can be reprinted with one click from the popup or the Options page.

Chapter 2

Install the Hub — Windows

One-time setup. After it finishes, the hub starts at every logon by itself.

There are two ways to install the hub on Windows. Way A is the Setup EXE — a normal installer window. Way B is the one-click BAT file — no window, just a black console that does everything. Both use the Python runtime bundled inside the package, so you never need to install Python yourself. Both register the same auto-run Startup app called PrintHub Pro, and the hub shows a tray icon while it runs.

Way A — Setup EXE (recommended)

1
Unzip the package first. Right-click the downloaded ZIP → Extract All. Do not run the EXE from inside the ZIP window — it must be a real folder on disk, for example D:\printer\PrintHub-Pro-1.7.2.
2
Remove the Windows block. Windows marks downloaded files as "from the internet" and may show "Windows cannot access the specified device, path, or file". Right-click the file installer\PrintHub-Pro-Setup-1.5.0.exe → Properties → tick Unblock → OK. Or run the PowerShell line below once — it unblocks the whole folder:
Get-ChildItem 'D:\printer\PrintHub-Pro-1.7.2' -Recurse -File | Unblock-File
3
Double-click the Setup EXE. If a blue Windows protected your PC screen appears, click More info → Run anyway. This warning appears once because the installer is not digitally signed.
4
Follow the wizard. Next → accept the license → Install. It copies everything to %LOCALAPPDATA%\PrintHubPro, registers auto-run as the Startup app “PrintHub Pro”, and starts the hub. No admin rights and no Python setup are needed. Click Finish — the hub is live, and its tray icon appears near the clock.

Way B — one-click BAT (no wizard)

1
Unzip the package (same as above).
2
Double-click install\install-windows.bat. It removes the internet block from all files, stops any old hub, uses the bundled Python runtime, installs SumatraPDF if winget is available, registers auto-run, starts the hub and health-checks it. No questions, no admin rights. Afterwards a “PrintHub Pro” tray icon appears near the clock — right-click it for the status page, a test page, pause, auto-run on/off and exit.
3
Wait for the green line "Hub is running — health check passed". The window can be closed afterwards.
SumatraPDF is required for silent PDF printing on Windows. The BAT installer installs it automatically. The Setup EXE only checks it — if it is missing, install it yourself (see Chapter 8, fix #3), then run the installer once more.

How to remove it

Uninstall on Windows

Setup EXE install: Windows Settings → Apps → Installed apps → PrintHub Pro → Uninstall (or Start Menu → PrintHub Pro → Uninstall). This also removes the auto-run Startup app.

BAT install: run install\UNINSTALL-WINDOWS.bat. Print history in %USERPROFILE%\.printhub is kept either way.

Chapter 3

Install the Hub — Linux & macOS

Native packages and one command in the terminal.

On Debian, Ubuntu or Mint, use the native .deb package. It installs to /opt/printhub, adds a systemd user service that starts at login and restarts on crash, plus an XDG autostart fallback, and a printhub command line tool. On macOS or any other Linux, use the universal shell installer instead — it needs no root (sudo) for the core setup.

1
Debian / Ubuntu / Mint — open a terminal in the package folder and run:
sudo apt install ./printhub-pro_1.7.2_all.deb
The service starts immediately and at every login.
2
macOS / other Linux — run:
bash install/install-unix.sh
It registers a LaunchAgent (macOS) or a systemd --user unit (Linux) automatically.
3
Verify — open http://127.0.0.1:9235/health in a browser, or run printhub doctor for a full self-check of printers and browser detection.
Uninstall on Linux

Remove the package with sudo apt remove printhub-pro, or run bash install/uninstall-unix.sh for the script install. Both stop the hub and remove the auto-run registration; print data in ~/.printhub is kept.

Chapter 4

Install the Chrome Extension

Five minutes in Chrome, Edge or Brave. No store needed.

The extension is the part that lives inside your browser. It is loaded in "developer mode" directly from the folder — this is normal for private extensions and takes one minute. Do these steps once per browser.

1
Open the extensions page. Type chrome://extensions in the address bar and press Enter (in Edge: edge://extensions).
2
Turn on Developer mode. The switch is at the top-right corner of the extensions page.
3
Click Load unpacked and select the extension folder from the package. A "PrintHub Pro" card appears.
4
Pin the icon. Click the puzzle-piece icon in the toolbar → push the pin next to PrintHub Pro. The icon stays in the toolbar for daily use.
5
Connect. Click the PrintHub icon → press the Connect button. The status line turns green and shows Connected with the hub version. The default token PrintHub-2024 matches the hub out of the box — nothing to type.
Note: Chrome may show a "Disable developer mode extensions" bubble at startup. Keep clicking Keep — the extension is yours and safe. If you ever reload the extension, press Connect again.
Chapter 5

First Test Print

Two checks that prove everything works: hub health and a real test page.

Before daily use, confirm that the whole chain works. The hub offers a health page in any browser, and the extension popup can print a built-in test page with one click. If both succeed, your setup is complete — real PDFs will behave the same way.

1
Check the hub. Open http://127.0.0.1:9235/health in the browser. You should see a short line with "ok": true and the version. If the page does not open, the hub is not running — see Chapter 8, fix #5.
2
Make sure a printer is default. Windows: Settings → Bluetooth & devices → Printers & scanners → click your printer → Set as default. Also switch off "Let Windows manage my default printer", because it can silently change the printer back.
3
Print the test page. Click the PrintHub icon in the toolbar → press Test page. Paper should come out within a few seconds. The popup shows the job in Recent jobs with a green "printed" state.
Success? You are done with setup. From now on, printing just happens — open any PDF or use the right-click menu. Problems? Go straight to Chapter 8.

Chapter 6

Daily Printing

After setup, printing is automatic. These are the everyday actions.

There is no "print dialog" in PrintHub Pro — that is the point. You keep working in the browser, and paper comes out. Use whichever method fits the moment; all of them end in the same silent print job on the default printer.

Open any PDF — it prints

With SIMPLE MODE on (default), every PDF you open in the browser prints silently and its viewer tab closes itself. Perfect for lab reports and downloaded invoices.

Right-click any page

Right-click anywhere → PrintHub Pro → Print this page. The page is rendered to paper exactly as you see it, without any dialog.

Popup buttons

Toolbar icon → Print this page, Save as PDF (file instead of paper), Print screenshot (exact visual snapshot), Test page, and Pause to hold all jobs temporarily.

Reprint from history

Popup → Recent jobs, or Options → Job history (last 100). Click Reprint on any line — useful when paper jammed or the printer was offline.

Automatic printing with routing rules

Rules print URLs without even opening them in a tab. When the browser loads a URL that matches a rule, the extension sends it straight to the hub. Your package already ships with one example rule for *://www.htncr.org/lab/medical_reports/* — every medical report link on that site prints automatically the moment it is opened. Add more rules in Options → Auto-print & routing rules using patterns like:

  • *://www.example.com/invoices/pdf/* — every PDF link under /invoices/pdf/
  • *://portal.hospital.org/report/*print=1* — pages marked print=1
  • <all_urls> — careful: matches everything
Duplicate protection: the same URL is not printed twice within 60 seconds, so opening a report twice does not waste two sheets of paper.
Chapter 7

Settings That Matter

A quick tour of the Options page. Defaults are fine for most users.

Open the Options page from the popup (Options button) or from chrome://extensions → PrintHub Pro → Details → Extension options. Everything saves instantly — there is no Save button to hunt for. The table below lists the sections in the same order as the page, with the settings that matter most in daily use.

Options sectionWhat to set
Connection Hub URL http://127.0.0.1:9235 and token PrintHub-2024. Only change the token if you changed it on the hub too.
Printing Leave the printer box empty to use the Windows default printer, or type an exact printer name to always use one specific device.
Auto-print & routing rules URL patterns that print automatically when loaded. One pattern per line; first matching rule wins.
Behavior Print every PDF opened in the browser (simple mode) — keep ON for the zero-click promise. "Open the URL in a new tab" vs "stay silent" controls what happens with failed or non-PDF links. Auto-close tabs keeps the browser clean.
Job history (last 100) Every job with time, printer, status and a Reprint button. History lives on your disk, not in the cloud.
Developer API Lets other pages or your own tools call window.printhub.print() directly. Safe to ignore if you only use the browser.
Chapter 8

Troubleshooting

The six problems that cover almost every report — and their fixes.

#1 "Windows cannot access the specified device, path, or file" when running the Setup EXE

This is the download block, not a broken file. Right-click the EXE → Properties → tick Unblock → OK. Or unblock the whole folder once in PowerShell:

Get-ChildItem 'D:\printer\PrintHub-Pro-1.7.2' -Recurse -File | Unblock-File

If it still fails after unblocking, your antivirus is quarantining it — check Windows Security → Protection history and allow the file. The BAT installer is never blocked this way, so you can always use it instead.

#2 "Python 3 was not found on this PC"

This message belongs to version 1.3.0 or older. Version 1.7.2 carries its own Python runtime inside the installer — the message can no longer appear. Download PrintHub-Pro-Setup-1.5.0.exe (9.5 MB) and install it. No Python install from python.org is ever needed.

#3 Nothing prints — no paper, no error

On Windows, silent PDF printing needs SumatraPDF. Open http://127.0.0.1:9235/health — if "sumatra_found" is false, install it: run winget install --id SumatraPDF.SumatraPDF -e --silent in PowerShell, or download it from sumatrapdfreader.org. Then run install-windows.bat once more so the hub restarts and detects it.

Also check "default_printer" — if it is null, see fix #4. If both are fine, the cause is in the log: open fix #6.

#4 No default printer / prints to the wrong printer

Windows: Settings → Bluetooth & devices → Printers & scanners → select the printer → Set as default. Turn off "Let Windows manage my default printer" — it can switch the default silently. To force one printer for every job, type its exact name in Options → Printing.

#5 Extension shows "Not connected" / hub missing after reboot

Check http://127.0.0.1:9235/health in the browser. If it does not open, the hub is stopped: run install\install-windows.bat again — it restarts the hub and repairs auto-run. Then press Connect in the popup. If health works but the popup stays red, the token in Options → Connection must match the hub (PrintHub-2024 by default).

#6 Deep diagnosis — read the log / other PCs cannot reach the hub

The hub writes every start and every print attempt to %USERPROFILE%\.printhub\hub.log (Linux/macOS: ~/.printhub/hub.log). Open the last lines after a failed job — the exact error is there. For printing from another computer or phone, enable LAN mode in the hub config and open port 9235 in the firewall; the token stays required.
