How to publish PrintHub Pro on the Chrome Web Store

Follow the steps in order. Everything you need is in this folder — the upload zip, the screenshots, the privacy policy, and every text you have to paste. Time needed: about 45 minutes (review by Google takes 1–7 days after that).

Why a new zip? Your old PrintHub-Pro-Extension-v1.4.0.zip has the files inside an extension/ folder. The store will refuse it with "manifest.json is missing or not at the root". Always upload the zip from this kit.

1Register as a Chrome Web Store developer (one-time $5)

  1. Turn on 2-Step Verification for your Google account first (the store requires it): myaccount.google.com/security
  2. Go to the Developer Dashboard: chrome.google.com/webstore/devconsole
  3. Sign in with your Google account (use the account you want shown as the publisher).
  4. Accept the agreement and pay the one-time US$5 registration fee (card).
  5. Under Account → Account details, set your seller/publisher name (e.g. Bitdream IT) and a contact email users can see.

2Put the privacy policy online (10 minutes, free)

The store requires a public privacy policy URL for extensions that ask for broad site access — yours does (<all_urls>). The easiest free host is GitHub Pages on your existing repo:

  1. Copy privacy-policy.html and PRIVACY-POLICY.md into the root of the PrintHub-Pro repo, then push: 
    git add privacy-policy.html PRIVACY-POLICY.md
git commit -m "Add privacy policy"
git push origin main
  2. On GitHub open the repo → Settings → Pages.
  3. Under "Build and deployment" set Source = Deploy from a branch, Branch = main / / (root), Save.
  4. Wait ~1–2 minutes. Your page is now live at: 
    https://bitdreamit.github.io/PrintHub-Pro/privacy-policy.html
    Open it to confirm. This exact URL is what you paste in Step 5.

3Create the item and upload the zip

  1. In the Developer Dashboard click New item.
  2. Drag / choose PrintHub-Pro-ChromeWebStore-1.5.0.zip → upload.
  3. When asked "Why are you requesting these permissions", tick that host permissions are needed — full justifications come in Step 5.

4Fill the "Store listing" tab

Copy-paste everything from STORE-LISTING-TEXTS.md (sections 1–4):

  • Name → "PrintHub Pro — Print from Any Web Page"
  • Short description → the 123-character text
  • Description → the detailed text
  • Category = Productivity  ·  Language = English (United States)
  • Screenshots: upload the 3 PNGs from screenshots/ in order 1→2→3. Optionally add promo-tile-440x280.png under "Promotional images".
  • The store icon is taken automatically from the zip — nothing to upload.

5Fill the "Privacy" tab (this decides approval)

  1. Privacy policy URL → https://bitdreamit.github.io/PrintHub-Pro/privacy-policy.html
  2. Single purpose → paste section 5 of STORE-LISTING-TEXTS.md.
  3. Permission justifications → paste each text from section 6 next to its permission (host permissions, tabs, activeTab/scripting, storage, notifications, contextMenus).
  4. Data usage → tick "This item does not collect any user data" and follow section 7 (also tick the three compliance certifications: no selling, no unrelated use, no creditworthiness).
  5. Default locale data-collected answers: everything No.

6Distribution tab + submit

  1. Distribution: Visibility = Public, countries = all (keep the default).
  2. Pricing: keep Free (Chrome Web Store has no paid extensions anymore).
  3. On the Package tab you can paste the "Notes for reviewers" text (STORE-LISTING-TEXTS.md section 8) in the review notes field when submitting — this explains the local hub and prevents a false "broken extension" rejection.
  4. Click Submit for review.

7Wait for review

  • Typical time: a few hours to 7 days. Extensions with <all_urls> content scripts sometimes take the full week — this is normal, do not resubmit while waiting.
  • Status in dashboard: Pending review → Published (or Rejected with a reason by email).
  • You can edit the draft listing while it is in review, but big edits can restart the clock.

8After approval

  • Your store link looks like: https://chromewebstore.google.com/detail/printhub-pro/ITEM_ID
  • Add the link to the GitHub README ("Install from Chrome Web Store" section) and to the hub app docs.
  • Optional: add the official store badge image to the README.

Future updates (v1.4.1 and later)

  1. Bump version in extension/manifest.json (and the other 9 version anchors as usual).
  2. Rebuild the store zip: python scripts/build_store_zip.py (edit the OUT filename/VERSION inside the script).
  3. Dashboard → your item → Package → upload the new zip → Submit for review. Updates to the listing text are made in the "Store listing" tab in the same go.

Common rejection reasons — and how this kit already handles them

Google rejects when…Your kit
The zip is missing manifest.json at the root Kit zip is built with the manifest at root (verified).
"Broken functionality" — reviewer cannot test it Reviewer notes explain the hub-less state is a graceful "Hub not running" screen; hub link + test steps provided.
Broad <all_urls> without a strong reason Full justification text written (user-triggered printing + opt-out in Options).
Missing privacy policy Policy written + GitHub Pages steps (Step 2).
Screenshots don't match the real UI Screenshots were rebuilt from the real popup/options layout and labels.
Remote code / obfuscated code None — all JS is local and readable; the extension never downloads code.
