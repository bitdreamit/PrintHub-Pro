1. Plain PDF links — zero code

Click a link. With the extension installed the PDF prints silently (one click = one job). Without it, the link opens normally — the browser fallback is automatic.

2. Any element with data-printhub

Buttons, cards, rows — anything carrying a URL in data-printhub prints that URL.

3. How it decides

SituationWhat happens
Extension + hub runningSilent print — toast Sent to printer (job N). No tab, no dialog.
Extension missing / disabledClick is not intercepted — the link opens the URL exactly like before.
Print fails (hub off, printer error)The URL opens in a new tab (browser fallback), toast explains it.
Double click / fast re-clickSwallowed by a 1.5 s cooldown — one click = one job, never two copies.
Page's own script already handled the clickPrintHub Auto stands down (no double handling).
Install on any page: <script src="printhub-auto.js"></script> — that's all. Optional customisation: PrinthubAuto.init({ selector:'.print-btn', title:'Report' }), manual API: PrinthubAuto.print(url, 'Title'). Sample links point to files that do not exist here — they only demonstrate the click behaviour.
