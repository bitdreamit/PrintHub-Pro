PrintHub Pro

Print from any web page to any printer · silent · 100% local · MIT open source

Connection

Link the extension to the PrintHub Pro hub running on this computer.

Start the hub with python printhub.py serve. Default token: PrintHub-2024. Change it with the PRINTHUB_TOKEN environment variable.

Printing

Where jobs go when no routing rule matches.

Auto-print & routing rules

First matching rule wins. Patterns are globs: *://www.htncr.org/lab/medical_reports/*. Auto = print automatically when the URL is opened.

Behavior

Print every PDF opened in the browser (simple mode)

ANY PDF you open - any site, any URL - is printed silently and its tab closes. No print view, no dialog, no rules needed. Turn off to auto-print only URLs matching your rules below.

Intercept window.print()

Web apps (Odoo, POS, dashboards) that call window.print() are printed silently through the hub instead of opening the dialog. Also intercepts Ctrl+P / Cmd+P.

Close tab after auto-print

When a rule auto-prints an opened URL, the tab is closed right after the job is queued - zero browser view, the paper just comes out.

When a page print call fails

Controls the automatic fallback of printPdfLink() / printPdf() on web pages: if the hub cannot print a PDF (hub off, printer error, not a PDF), either open the URL in a normal tab so the browser prints it the default way, or stay completely silent - nothing opens, the failure is only logged in the job history. A per-call opts.fallback (true/false) in page JS overrides this setting.

Right-click menu

Add "PrintHub Pro" to the context menu (print page / selection / linked PDF / screenshot).

Toolbar badge

Green OK / red ! on the extension icon after every job.

Job history (last 100)

Served by the hub from SQLite. Survives restarts.

Developer API - window.printhub

Available on every page (when the hook is enabled). All methods return Promises.

<script>
  await window.printhub.status();            // hub health
  await window.printhub.printers();          // [{name, is_default}]
  await window.printhub.printPage({title});  // print current page
  await window.printhub.printPdf(url, {title, printer});
  await window.printhub.print({
    title: 'Receipt 12', printer: '', copies: 1,
    text: '|center|HELLO|',        // or:
    html: '<h1>Invoice</h1>',      // or:
    pdfBase64: 'JVBERi0...',       // or:
    pdfUrl: 'https://.../report.pdf'
  });
</script>
Direct HTTP also works from any language: POST http://127.0.0.1:9235/print with header X-PrintHub-Token - see docs/API.md in the package.
