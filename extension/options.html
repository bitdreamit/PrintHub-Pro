Power switches

AdvPrint enabled (master switch)

OFF = the extension stops completely: no printing, no auto-print, no window.print() hook, no page API, no context menu. A gray OFF badge shows on the toolbar icon. Use it when you want the browser to behave 100% natively without uninstalling AdvPrint.

Queue mode

ON = every job goes through the hub queue in order (Pause/Resume in the popup or hub works, big jobs line up). OFF = instant print - each job is handed straight to the printer the moment it arrives (hub sends queue:false), nothing waits behind earlier jobs, Pause has no effect. If no printer is active (offline / paper-out / error) the job is auto-queued instead of failing and prints when the printer is back (v2.3, fallback can be turned off with POST /config {"instant_auto_queue": false}).

Debug mode - find problems fast (v2.3)

ON = this extension reports every error it hits (network failures, rejected token, print-call exceptions, jobs that ended failed/dead) to the hub, and the hub logs verbosely. Open the Debug tab (or the dashboard Debug card, or /debug) to see WHEN / WHY / WHERE printing fails - no guessing. Turn off again when everything works.

Retry when the hub comes back

If the hub is offline, jobs are kept in the browser and sent automatically as soon as the hub answers again (checked every minute).

Auto-print & routing rules

First matching rule wins. Type: glob (*://www.htncr.org/lab/*) or regex (v2.0). Title: only match when the page title contains the text. On: per-site on/off. Auto = print automatically when the URL is opened.

Behavior

Print every PDF opened in the browser (simple mode)

ANY PDF you open - any site, any URL - is printed silently and its tab closes. No print view, no dialog, no rules needed. Turn off to auto-print only URLs matching your rules below.

Intercept window.print()

Web apps (Odoo, POS, dashboards) that call window.print() are printed silently through the hub instead of opening the dialog. Also intercepts Ctrl+P / Cmd+P.

Close tab after auto-print

When a rule auto-prints an opened URL, the tab is closed right after the job is queued - zero browser view, the paper just comes out.

When a page print call fails

Controls the automatic fallback of printPdfLink() / printPdf() on web pages: if the hub cannot print a PDF (hub off, printer error, not a PDF), either open the URL in a normal tab so the browser prints it the default way, or stay completely silent. A per-call opts.fallback (true/false) in page JS overrides this setting.

Hub settings (advanced) - live in config.json, saved over POST /config

Queue & retries

Hold jobs while the printer reports offline

Jobs wait (status "held") until the printer is ready again - nothing is lost. Turn off if your printer always reports offline but still prints (misreported status).

Instant print fallback to queue

Queue mode OFF + printer not active: the job is auto-queued instead of failing, and prints when the printer is back (v2.3).

Security

Strict token mode (header only)

ON = mutating calls (POST) must send the token in the X-AdvPrint-Token header (the extension does this anyway). OFF = token in the URL/body is also accepted (1.x compatibility).

Never lock out this PC (127.0.0.1)

Recommended ON: a stale token in one Chrome window can never lock out your own dashboard, tray and extension (v2.0.1 rule).

Developer API - window.advprint

    
Available on every page (when the hook is enabled). All methods return Promises.


<script>
  await window.advprint.status();            // hub health
  await window.advprint.printers();          // [{name, is_default, status}]
  await window.advprint.printPage({title});  // print current page
  await window.advprint.printPdf(url, {title, printer});
  await window.advprint.print({
    title: 'Receipt 12', printer: '', copies: 1,
    priority: 1,                    // v2.0: urgent first
    pages: '1-3,5',                 // v2.0: range - v2.2: odd/even too
    per_sheet: 2,                   // v2.1: n-up
    quality: 'draft',               // v2.2: draft|normal|high|'600dpi'
    dpi: 600,                       // v2.2: explicit DPI
    scale_pct: 150, margin_mm: 8,   // v2.1: rendered jobs
    duplex: 'duplex',               // two-sided
    paper_size: 'A4', orientation: 'landscape',
    profile: 'Invoice',             // v2.0: hub print profile
    text: '|center|HELLO|',         // or:
    lang: 'escpos',                 // v2.0: raw ESC/POS or ZPL
    html: '<h1>Invoice</h1>',      // or:
    pdfBase64: 'JVBERi0...',       // or:
    pdfUrl: 'https://.../report.pdf'
  });
</script>
