WHY DID MY OLD VERSION SAY "SumatraPDF not found"?
  The hub finds SumatraPDF automatically for EVERY Windows user (your
  user name is never hardcoded):
    C:\Users\<your-name>\AppData\Local\SumatraPDF\SumatraPDF.exe
    both Program Files, Windows registry (per-user + per-machine), PATH,
    and - even when the hub runs as a Windows SERVICE under another
    account - an all-users profile scan (C:\Users\*\...).
  It re-checks on EVERY print job - no restart needed. Failed jobs
  auto-retry. Still not found? Dashboard -> Settings -> paste the path.

UPDATE IN 3 STEPS
  1. Run PrintHub-Pro-Setup-2.5.0.exe (installs over the old version,
     keeps your job history + settings in %USERPROFILE%\.printhub).
  2. Chrome -> chrome://extensions -> PrintHub Pro -> click RELOAD.
  3. TEST IT LIVE (proves the REAL printer was hit):
        http://127.0.0.1:9235/dashboard?token=<your token>
     The dashboard has a "Live debug & test tool" section - click
     "Send test print & watch live" and read the verdict:
     REAL PRINTER HIT / SAVED / HELD / FAILED+reason.
     Full step-by-step test: docs/EXTENSION-TEST.md

NO PRINTER RIGHT NOW?
  - Print to "Microsoft Print to PDF": the hub saves the PDF directly
    into Downloads\PrintHub (no dialog, no SumatraPDF needed).
  - Or choose "File (PDF)" / "__file__" as the printer.
  - Jobs for an offline printer wait as HELD and print automatically
    when the printer is back ("Print now" / Release ALL forces them).
