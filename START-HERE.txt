THE TOKEN
  Fresh installs: a PRIVATE RANDOM token (shown once in hub.log,
  readable with "python advprint.py token" or the config file).
  Upgraded pre-2.0 installs: old default PrintHub-2024 keeps
  working until you rotate it (the dashboard warns you).
  Lost it? Stale bookmark? -> the dashboard error page has the
  one-click fix, or tray -> Open dashboard, or extension ->
  Detect token. Rotate: dashboard "Rotate token" button or
  python advprint.py token-rotate.

NO PRINTER RIGHT NOW?
  - Print to "Microsoft Print to PDF": the hub saves the PDF
    straight into Downloads\AdvPrint (no dialog).
  - Or choose "File (PDF)" / "__file__" as the printer.
  - Jobs for an offline printer wait as HELD and print
    automatically when the printer is back.
